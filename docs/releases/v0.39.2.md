# v0.39.2 — Saves and steadier speed

- **Saves**: Menu > Saves keeps an autosave, a backup and up to ten named saves (Load, Overwrite, Rename, Delete), compressed and stored in the browser's IndexedDB. Export writes `.json.gz`; older saves and files still load.
- **Steadier speed**: drawing is limited to what the village can afford, so a display that calls the game 120 to 250 times a second (the Claude app's built-in browser) no longer starves the simulation.
- **Diagnostics**: the report says what is limiting the speed and keeps the last 30 seconds of timings.
